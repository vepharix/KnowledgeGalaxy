# First experiment fixture

This directory contains the deliberately small and interpretable input for the first three-dimensional spatial experiment.

Every node is a `ResearchField`. The `hierarchy`, `dependencies`, and `relatedness` collections correspond to H, D, and R in the current model. Every supplied number is marked as a curated experimental assumption. The values are intended to make mathematical behavior inspectable; they are not objective measurements, expert consensus, or claims that missing pairs are unrelated.

`emergence_time` is descriptive metadata only and is not read by the spatial optimizer.
