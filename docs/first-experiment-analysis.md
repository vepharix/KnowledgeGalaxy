# 第一次三维知识空间实验分析

## 实验范围

第一次实验使用 data/first_experiment/fixture.json 中的 24 个 ResearchField，覆盖数学、统计、计算机科学、人工智能、机器学习、语言、视觉、物理、生物、神经科学和经济学。H、D、R 均为运行前人工策展并附 provenance 的实验假设，目的在于让几何行为容易解释；这些数值不是客观测量，也不能用本次结果反向证明它们正确。

实验使用默认 SpatialConfig：固定随机种子为 20260816，依赖正则化系数为 0.15，依赖亲和系数为 0.70，径向损失权重为 1.8，排斥损失权重为 0.12，共执行 3500 步确定性 Adam 优化。机器可读结果位于 work/first-experiment.json，静态诊断投影位于 outputs/first-experiment.svg。

## 数值结果

优化总损失从初始的约 436.23 降至 79.625，并在约第 750 步后进入相对稳定区间。最终各项指标如下：

| 指标 | 结果 |
| --- | ---: |
| 亲和损失 | 43.677 |
| 径向损失（未加权） | 18.149 |
| 径向损失（乘以 1.8） | 32.669 |
| 排斥损失（未加权） | 27.326 |
| 排斥损失（乘以 0.12） | 3.279 |
| 总损失 | 79.625 |
| 依赖深度—实际半径 Pearson 相关系数 | 0.80752 |
| 实际半径相对目标半径的平均绝对误差 | 0.68144 |
| 最小节点间距 | 0.98750 |
| 坐标有限性 | 全部有限 |

固定种子复现测试通过，相同 fixture 与配置会产生完全一致的坐标；没有出现 NaN 或无穷值。由此可以确认实现满足确定性和基本数值稳定性，但损失仍然较高，说明不同约束之间存在尚未消解的竞争。

## 观察到的结构

依赖深度总体上形成了预期的由内向外趋势。Mathematics 的归一化深度为 0，目标半径为 1.100，实际半径为 1.233；Linear Algebra 和 Probability Theory 的实际半径分别为 1.766 和 1.822。较深的 Transformer Models、Computational Linguistics 和 Large Language Models 位于更外部，实际半径分别约为 4.050、4.514 和 4.692。0.80752 的深度—半径相关系数说明这一趋势清楚存在，但还没有精确满足每个节点的目标半径。

局部关系也产生了可辨认的连续结构。静态投影中，数学、统计、机器学习、深度学习、Transformer Models 与 Large Language Models 形成一条连续但并非树状的区域；Data Science 位于 Statistics 与 Machine Learning 的联系附近，Computational Linguistics 位于语言处理与大语言模型附近。Physics、Biology 和 Economics 没有被强行塞入同一个人工智能簇，而是形成较外部的支路。这个结果初步支持“交叉领域可以由多组相关关系形成中间位置”，但二维投影只能用于诊断，仍需在可旋转的三维视图中复核遮挡与前后关系。

层级密度区域体现了层级和几何的分离。Mathematics 的密度区域在当前阈值下几何上包含了 Machine Learning、Deep Learning 和 Signal Processing，Artificial Intelligence 的区域包含了 Optimization，Deep Learning 的区域包含了 Natural Language Processing；这些几何包含都没有生成新的 H。因而实现已经满足“区域重叠不等于层级成员”的约束，也说明未来的云区可以允许相关领域穿行和交叠。

## 暴露出的冲突

第一项问题来自几何亲和的截断。全部 276 个无序领域对中，只有 50 对具有正 G，其中 22 对在相加后被 clip 到 1。大量饱和对失去了强弱差异，而未提供 R 的领域对又没有亲和约束。当前空间因而同时存在“少数关系过于同质”和“多数关系没有局部吸引”的现象。它首先是 G 的组合规则与 fixture 稀疏度造成的，不需要立即引入新的语义变量。

第二项问题是亲和目标和径向目标存在明显竞争。Machine Learning 的归一化依赖深度为 0.514，目标半径 3.515，实际半径却只有 1.458；Artificial Intelligence 的目标与实际半径分别为 4.458 和 2.829，Computer Vision 分别为 4.990 和 3.209。与此同时，一些高亲和领域对仍远于目标距离：Machine Learning 与 NLP 的 G 为 0.928，目标距离 0.979，实际距离 3.369；Machine Learning 与 Statistics 的 G 已饱和为 1，目标距离 0.800，实际距离 2.708；AI 与 Machine Learning、Computer Vision 与 Deep Learning 也有类似残差。最终损失中亲和项和加权径向项占据主要部分，表明优化器不是简单地“没有收敛”，而是在两个不能同时完全满足的几何要求之间折中。

第三项问题来自依赖深度的全局可比性。Biology 和 Economics 在各自局部分量中接近依赖根节点，但归一化深度仍约为 0.4，没有像 Mathematics 那样靠近全局最低值。正则化最小二乘给每个分量确定了相对层次，随后一次全局 min-max 又把不同长度、不同连接强度的分量放在同一尺度上。当前结果因此不能说明所有局部基础领域天然应处于同一内层。

第四项问题是“没有指定中心学科”仍不等于“没有单一中心结构”。模型每一步使用全体节点的共同几何质心，并让所有领域围绕它满足目标半径。语义上没有预设 Mathematics 为中心，但几何上仍然只有一个径向参考框架。当数据将来包含多个弱连接知识簇时，这个假设可能产生人为的同心结构。

静态图还有标签轻微重叠的问题，尤其出现在 Transformer Models 与 Natural Language Processing 附近。这属于二维诊断渲染，不是知识模型失败；当前实现尚未包含标签避让、交互旋转或真正的体积云。

## 结论与下一步检验

第一次实验可以判定为部分成功。基础领域倾向内部、依赖较深领域倾向外部、强相关领域形成局部连续结构、交叉领域出现在相关区域之间，层级密度也能与语义成员关系保持分离。然而，径向目标与局部亲和之间的残差仍大，G 的截断造成强关系饱和，不连通分量的深度缺少可靠的全局尺度，而且单一质心仍隐含单一径向框架。因此，这次结果足以说明最小关系模型能够产生非随机结构，却不足以证明当前几何已经是稳定或唯一的知识空间。

下一轮应优先对现有数学项做消融和敏感性检验：比较不同 G 组合或非饱和映射，考察全局与分量内深度归一化，扫描径向权重和亲和权重，并在多个固定种子结果之间消除旋转和平移后比较稳定性。只有在这些检验仍无法解释失败时，才考虑扩展语义输入。自动计算 R、扩大有来源的数据集、可旋转三维视图和体积云渲染可以随后推进，但它们不应掩盖当前模型内部已经暴露出的约束冲突。
