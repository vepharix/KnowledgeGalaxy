# 假设与待决策

本文件把尚未验证的判断与已经确认的产品描述分开。标记为“假设”的内容只用于让研究可推进，后续可以被数据、专家复核或模型比较推翻。更完整的研究问题见 `model-research-questions.md`。

## 当前工作假设

1. 30–100 个实体足以暴露第一批身份、粒度、跨学科归属和关系语义问题，同时允许人工复核证据。
2. 通用 `KnowledgeEntity` 加非互斥 facets 可能比六种互斥节点类型更适合研究，但仍需与其他身份模型比较。
3. 第一个数据集应刻意选择学科重叠明显的对象，而非追求分类整齐或主题封闭。
4. 来源支持应绑定到具体断言，而不只是绑定到整个实体。
5. 不确定性先用结构化状态加理由表达，是否引入统一数值置信度由实验决定。
6. 径向位置可能需要任务相关或多中心模型；单一“知识中心”并非预设条件。
7. Phase 1 使用可重复的离线数据与模型运行，不开发视觉界面。
8. 两周是约 10 个工作日、由一名主要研究/开发者完成；若投入不同，范围需要重估。

## 首批待决策

以下选择会影响实现，但目前没有足够依据直接确定：

- 核心用户：研究型使用者、工程技术使用者，或面向公众的知识叙事，三者对信息密度的要求不同。
- 实体身份与粒度：抽象概念、理论版本、具体文献和工程系统如何拆分或合并。
- 分类模型：学科是实体、标签、层级断言还是语境；多重归属如何保留。
- 关系词汇：层级、先修、引用、依赖、改进和应用的边界、方向与证据标准。
- 相似度的长期定义：Phase 1 首轮主要比较文本语义模型，但专家判断、关系上下文或混合模型是否适合作为长期表示仍待实验。
- 径向模型：中心的定义、单中心或多中心、任务是否改变半径。
- 时间语义：实体和断言分别需要哪些时间，冲突与不确定时间如何表示。
- 数据来源与许可：原型具体使用哪些开放数据源，以及哪些关系需要人工整理。
- Phase 1 成功度量的扩展：首轮采用锚点预期和最大模型分歧；是否增加标注者一致性、失败案例数量或专家语义清晰度评价仍待决定。
- 可视化进入条件与技术栈：推迟到模型研究完成后决定。

## 已确认的首轮实验选择

以下内容已经由用户确认，具体背景与后果见 [0001-phase-1-experiment.md](decisions/0001-phase-1-experiment.md)：

- 使用 Python 命令行实验框架，产出以中文为主的静态 HTML 报告，不开发前端应用。
- 实验域为几何、拓扑、微分几何，并加入少量理论物理边界对象。
- 目标样本构成为约 70% 数学概念、20% 定理/结构/方法、10% 理论物理对象；比例是抽样配额，不是本体类型系统。
- 首轮主要比较语义相似模型，采用锚点预期与最大模型分歧结合的评价。
- 文本表示、元数据判断和图结构统计保持为三条独立实验轨道；首轮报告不得把它们合并成一个总距离。
- 计算文本以英文为主，研究报告以中文为主。
- 模型默认本地运行。外部嵌入 API 仅作为显式启用的对照轨道，并只发送已标为公开、许可或使用依据清楚的数学定义。

## 决策规则

一项假设只有在得到用户确认、数据检查或小型试验支持后，才转为决策。会长期影响代码或数据的决定，应在 `docs/decisions/` 中留下简短记录，包括背景、选择、替代方案和后果。
