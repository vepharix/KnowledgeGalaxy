# 决策 0001：首轮 Phase 1 实验设计

- 日期：2026-08-14
- 状态：已确认

## 背景

项目需要在两周和 30–100 个实体的边界内，先回答知识对象与相似模型是否可解释，而不是开始三维表现。为了让第一步可以重复运行，还需要固定实验载体、问题域、抽样构成和首轮评价方式。

## 决定

首轮采用 Python 命令行实验框架，生成以中文为主的静态 HTML 报告。研究域限定为几何、拓扑和微分几何，另加入少量理论物理边界对象。完整样本的目标构成为约 70% 数学概念、20% 定理/结构/方法、10% 理论物理对象；这是抽样配额，不是互斥类型或产品本体。

首轮主要比较英文计算文本上的语义相似模型。评价同时使用人工锚点预期和模型最大分歧案例。文本、元数据与图结构分别运行和保存，不合成为统一知识距离。报告主要使用中文解释结果。

模型默认在本地运行。外部嵌入 API 只用于对照实验，必须由操作者显式启用；发送范围限制为数据中明确标记可外发的公开数学定义，不发送来源笔记、人工判断、图关系或其他元数据。

## 考虑过的替代方案

浏览器界面和三维原型会把当前注意力转移到布局与交互，因此留到 Phase 2。只选单一数学分支较容易形成整齐近邻，但不利于暴露跨域桥接与边界问题。把文本、元数据和图结构立即混合可以得到一个分数，却会使模型差异难以归因。只依靠人工锚点覆盖不足，只看模型分歧又缺少先验判断，因此两者并用。

## 后果

第一版框架应能在无网络和无第三方 Python 依赖的环境中运行至少两种本地基线，并保留外部嵌入结果的可选导入或显式调用入口。报告必须分别展示锚点表现与分歧案例，并写明样本规模和外推限制。后续仍需决定实体粒度、关系词汇、径向模型及核心用户；本决策不提前回答这些问题。
