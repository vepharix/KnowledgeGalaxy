# 新突触

“新突触”设想为一个带时间轴的人类知识联系网络。长期方向可能使用三维空间帮助探索知识，但在知识对象、关系语义和空间含义尚未澄清前，三维表现不作为当前工作的前提。

项目当前处于 Phase 1：知识模型研究阶段。本阶段使用 30–100 个刻意跨学科、允许领域重叠的对象，对候选模型进行小规模实验；不开发三维原型。

## 当前研究立场

- `KnowledgeEntity` 是用于实验的通用身份抽象；什么有资格成为实体仍待研究。
- 概念、论文、专利、工程成果、产品和历史事件只是六个候选分类标签，不是互斥类型或固定架构。
- 引用、依赖、改进和应用只是候选关系词汇，其方向、边界和充分证据仍需验证。
- 本体与身份、层级、先修关系、语义相似度、图连接性、径向位置和最终视觉距离必须分别建模与评估。
- 图中心性不能被直接解释为概念基础性；“基础知识靠近中心”仅作为可检验的径向模型之一。

这些描述中仍有未确定的产品选择；请以 [假设与待决策](docs/assumptions-and-decisions.md) 为准，不要把草案当成既定事实。
